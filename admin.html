    Arsip

    Google Drive

    Daftar berkas yang dapat dibuka langsung dari portofolio.

    Simpan tautan, bukan berkas besar.

    Unggah modul ke Google Drive, atur akses menjadi “Siapa saja yang memiliki link”, lalu tempel tautannya di sini. Portofolio akan menampilkan tombol yang langsung membuka arsip tersebut.

    Integrasi

    Google Drive

    Hubungkan akun Google untuk mengunggah modul dan video langsung dari studio ini.

    Belum terhubung
    Perlu Client ID dari Google Cloud Console.

    Integrasi ini menggunakan OAuth resmi Google dengan scope drive.file, sehingga aplikasi hanya dapat mengakses berkas yang dibuatnya sendiri. Ikuti panduan di bawah (sekali saja, gratis).

    Konfigurasi

    Tersimpan otomatis di browser.

    Uji Unggah

    Pastikan izin dan folder bekerja.

    Pilih berkas untuk diunggah PDF, gambar, atau video pendek · maksimal 6 MB untuk uji cepat

    Panduan Singkat

    1. Buka Google Cloud Console, buat project baru.
    2. Aktifkan Google Drive API pada menu APIs & Services.
    3. Atur OAuth consent screen (External, tambahkan email Anda sebagai test user).
    4. Buat OAuth Client ID tipe Web application.
    5. Tambahkan Authorized JavaScript origin: http://localhost:5500 dan domain hosting Anda.
    6. Tempel Client ID di kolom kiri, simpan, lalu klik Hubungkan.

    Panduan lengkap tersedia di berkas PANDUAN-GOOGLE-DRIVE.md pada folder proyek.

    Ganti Passcode

    Gunakan passcode yang kuat dan mudah Anda ingat.

    Passcode berhasil diperbarui.

    Backup & Restore

    Data tersimpan di browser ini saja.

    Export mencakup seluruh teks dan tautan. Foto yang diunggah lokal tidak ikut dalam JSON; gunakan Google Drive untuk arsip foto permanen.

    Reset Data

    Kembalikan seluruh konten ke contoh bawaan.

    Tindakan ini tidak dapat dibatalkan. Export data terlebih dahulu jika ingin menyimpan versi saat ini.
